# Triangle Learning Section

An interactive lesson on triangle types, by sides and by angles. Open `index.html` in a browser; there's no build step. `?screen=N` opens screen N directly.

- `js/` holds the geometry engine, the triangle renderer, the UI, the voice player and the 37 screen scripts (`js/screens.js`).
- `assets/` holds the background, the title thumbnail, the Start button and the voice-over clips.
- Voice-over: every line is voiced and revealed word by word. See [docs/VOICEOVER.md](docs/VOICEOVER.md) (`assets/vo/`, 100 clips, 1.35 MB).
